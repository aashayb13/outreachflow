# Quick Start Guide

## 1. Connect Apollo (one-time setup) - Already Done

Go to **Settings > Integrations** → Add **Apollo** → paste your API key → click **Test** → Save.

## 2. Create a List

Go to **Lists** → click **New List** → give it a name (e.g. "Plumbing Owners TX") → Create.

## 3. Import Contacts

Click into your list → click **Apollo Search** → fill in one or more filters:

- **Keywords** — e.g. "plumbing"
- **Job Titles** — e.g. "Owner, CEO"
- **Company HQ Location** — e.g. "Texas"

Click **Preview** to check results, then **Import to List**.

## 4. Create a Template

Go to **Templates** → click **New Template** → write your email in plain text. Use merge tags for personalization:

- `{{first_name}}` — contact's first name
- `{{company}}` — contact's company name

## 5. Send a Campaign

From your list detail view, click **Send Campaign** → pick your template → set subject line → **Create & Send Now**.

---

**That's it.** Lists → Import → Template → Send.
