# 01 — Infrastructure Setup

## Overview

This document covers the complete infrastructure setup: n8n Cloud, domain registration, DNS configuration, Google Workspace mailboxes, and account provisioning for all services.

---

## 1. n8n Cloud Setup

### Why n8n Cloud (vs Self-Hosted)
- No server management, automatic updates, built-in SSL
- Managed PostgreSQL database for workflow persistence
- Guaranteed uptime without DevOps overhead
- Built-in credential encryption
- Cost: ~$20-50/mo depending on plan (vs ~$10/mo self-hosted + maintenance time)

### Setup Steps

1. **Sign up at n8n.io** → Choose a plan that supports:
   - Webhook triggers (all plans)
   - HTTP Request nodes (all plans)
   - Sufficient workflow executions for your volume (~300-500/day)

2. **Configure instance:**
   - Set timezone to your local timezone (for scheduling)
   - Enable execution logging (for debugging)
   - Set up two-factor authentication

3. **Install required nodes** (most are built-in):
   - Webhook node (built-in)
   - HTTP Request node (built-in)
   - HubSpot node (built-in)
   - Filter node (built-in)
   - If node (built-in)
   - Switch node (built-in)
   - Set node (built-in)
   - Google Sheets node (built-in, for logging)

4. **Create credentials:**
   - Lead Magic API Key
   - Plusvibe API Key + Workspace ID
   - HubSpot OAuth2 connection
   - Google Sheets OAuth2 (for error logging)

### n8n Cloud Plan Recommendations

| Plan | Executions | Price | Fit |
|------|-----------|-------|-----|
| Starter | 2,500/mo | ~$20/mo | Tight for 10K leads/mo |
| Pro | 10,000/mo | ~$50/mo | Recommended — room to grow |
| Enterprise | Unlimited | Custom | Overkill for now |

**Recommendation:** Start with Pro plan. Each lead that passes through the full pipeline triggers one workflow execution. At ~300 leads/day passing ICP filters, you'll use ~9,000 executions/month.

## 2. Domain Registration

### Domain Strategy

Purchase **3 outreach domains** that are variations of your primary brand. These protect your main domain's reputation.

**Naming convention examples** (if primary is `patriottech.com`):
- `patriottechsystems.com`
- `getpatriottech.com`
- `patriottechgroup.com`

**Rules:**
- Never use your primary business domain for cold outreach
- Use `.com` TLD only (best deliverability)
- Avoid hyphens, numbers, or unusual TLDs
- Domain age matters — register now, even if you don't send for 3 weeks

### Where to Register
- Namecheap, Google Domains, Cloudflare Registrar
- Cost: ~$10-15/year per domain (~$4/mo total for 3)
- Enable WHOIS privacy on all domains

## 3. DNS Configuration (Per Domain)

Each domain needs three DNS records for email authentication. **This is critical for deliverability.**

### SPF Record
```
Type: TXT
Host: @
Value: v=spf1 include:_spf.google.com ~all
TTL: 3600
```

### DKIM Record
Generated by Google Workspace during setup. Example:
```
Type: TXT
Host: google._domainkey
Value: v=DKIM1; k=rsa; p=MIIBIjANBg... (Google provides this)
TTL: 3600
```

### DMARC Record
Start with monitoring mode, then tighten:
```
# Week 1-2: Monitor only
Type: TXT
Host: _dmarc
Value: v=DMARC1; p=none; rua=mailto:dmarc@yourdomain.com
TTL: 3600

# Week 3-4: Quarantine failures
Value: v=DMARC1; p=quarantine; rua=mailto:dmarc@yourdomain.com

# Week 5+: Reject failures (full protection)
Value: v=DMARC1; p=reject; rua=mailto:dmarc@yourdomain.com
```

### Custom Tracking Domain (for Plusvibe)
```
Type: CNAME
Host: track
Value: (provided by Plusvibe during setup)
TTL: 3600
```

### Verification Checklist
After DNS setup, verify with:
- [MXToolbox SPF Check](https://mxtoolbox.com/spf.aspx)
- [DKIM Validator](https://dkimvalidator.com/)
- [DMARC Analyzer](https://dmarcanalyzer.com/)

## 4. Google Workspace Mailboxes

### Setup: 3 Mailboxes Per Domain (9 Total)

| Domain | Mailbox 1 | Mailbox 2 | Mailbox 3 |
|--------|-----------|-----------|-----------|
| patriottechsystems.com | alex@... | michael@... | sarah@... |
| getpatriottech.com | alex@... | michael@... | sarah@... |
| patriottechgroup.com | alex@... | michael@... | sarah@... |

**Naming best practices:**
- Use real-sounding first names
- Avoid generic names (info@, sales@, noreply@)
- Each mailbox should have a complete Google profile (name, photo, signature)
- Consistent sender personas across domains

### Google Workspace Setup
1. Go to workspace.google.com → sign up for Business Starter ($7.20/user/mo)
2. Add each domain and verify ownership via DNS
3. Create user accounts for each mailbox
4. Enable DKIM signing in Admin Console → Apps → Google Workspace → Gmail → Authenticate email
5. Set up email signatures for each account

### Per-Mailbox Configuration
- **Display name:** First Last (consistent persona)
- **Profile photo:** Professional headshot
- **Signature:** Name, title, company, phone
- **2FA:** Enable on all accounts
- **Recovery email:** Set to your admin account

### Cost
- 9 mailboxes × $7.20/mo = **$64.80/mo** (Business Starter)
- Or 9 × $14.40/mo = **$129.60/mo** (Business Standard — more storage)

## 6. Security Checklist

- [ ] All accounts use unique, strong passwords (use a password manager)
- [ ] 2FA enabled on every service
- [ ] API keys stored in n8n's encrypted credential store (never in workflow JSON)
- [ ] Google Workspace admin account separate from sending accounts
- [ ] WHOIS privacy enabled on all outreach domains
- [ ] HubSpot Private App scoped to minimum required permissions
- [ ] n8n webhook URLs use authentication (Basic Auth or Header Auth)
